# 拾旅 iOS 新版需求差异审计

基线：用户提供的《拾旅 App 完整产品设计需求》（1353 行）。审计日期：2026-08-12。

## 已覆盖并增强

- `IOS-P01`：授权前说明、全部/部分照片权限、PhotoKit 全库元数据扫描；不依赖 9 张选择上限。
- `IOS-P02`：按常驻区域、离家距离、时间连续性和拍照密度发现旅行；返家照片切分相邻旅程；截图不参与发现。
- `IOS-P03`：沉浸式发现页、确认后轻量生成状态、隐藏误判旅程。
- `IOS-P04`：旅行 → Day → 事件 → 照片引用；每个事件默认精选最多 5 张。
- `IOS-P05`：旅程概览按“总结、轻量统计、路线、精彩时刻、每一天”组织。
- `IOS-P06`：Day 时段筛选、垂直事件流、浮动“一句话记忆”。
- `IOS-P07`：事件大图滑动、全部照片、地点/时间纠正、相邻事件合并、隐藏、换代表图、精选/取消精选、移除照片。
- `IOS-P08`：按 Day 过滤的记忆地图、照片节点、事件卡、地图与事件双向跳转。
- `IOS-P09`：旅行总结、足迹、收藏、保存/分享回忆卡片。
- `IOS-P10`：本地 JSON 旅行结构、缩略图磁盘缓存、独立缓存统计/清理；原图不复制到 App。
- `IOS-P11`：权限撤销保留文字结构；原图删除或不可访问时显示可恢复提示。
- `IOS-P12`：往年今日、随机回忆、城市与路线距离统计、旅行 JSON 导出。
- `IOS-P13`：拆分/删除事件、跨城市交通过渡、旅程级封面更换；所有用户修正跨重新扫描保留。

## MVP 边界

- 首版事实纠正闭环已包含相邻事件合并、从当前照片拆分事件、隐藏与删除事件。
- 无开发者云端 AI；地点名称使用 Apple 系统地理编码，图像理解使用 Apple Vision 本机能力。
- 当前 Windows 环境无法运行 iOS SDK；官方 Swift 编译、XCTest、真机大相册性能与权限矩阵仍需在 macOS/iPhone 完成。
